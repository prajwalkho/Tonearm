## Recommended sequence

1. **P0:** BL-01 catalog/deployment gate, then BL-02 actual player E2E baseline.
2. **P1:** BL-03 playback edge cases, BL-04 storage clarity, BL-05 protected playlist regression, BL-09 responsive checks, BL-10 accessibility, BL-12 import/export tests, BL-13 static-host validation.
3. **P2:** Search behavior, reviewed mood tagging, measured art optimization, catalog lint, player interaction polish, gradual code organization.
4. **P3:** Low-risk promotional link regression.

## Roadmap gates

- **Gate A — Requirements review:** confirm permanent/session meanings, browser matrix, expected Next/Previous rules, and cross-device sync need.
- **Gate B — Reliability:** implement manifest/build checks and player/UI tests; resolve high-severity failures.
- **Gate C — Usability/accessibility:** validate responsive layouts, keyboard, screen reader, reduced motion, and storage language.
- **Gate D — Release:** verify clean deployment, assets/audio, refresh/hash routes, and live-site smoke checks.

Do not add an account system, database, or backend unless Gate A confirms cross-device data synchronization is a required product outcome.
